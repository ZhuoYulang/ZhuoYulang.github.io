# Haolin Zuo Academic Homepage

Static academic homepage for GitHub Pages or any ordinary web server. The layout follows a Minimal Mistakes-style academic profile: sticky top navigation, left profile sidebar, publication cards, news timeline, dark mode, and publication search.

## Files

- `index.html`: page content and academic profile sections.
- `styles.css`: responsive layout and visual style.
- `scripts.js`: mobile navigation, dark mode, active section highlighting, back-to-top, and publication filtering.
- `assets/profile.jpg`: homepage portrait copied from the uploaded photo.

## Preview

Open `index.html` directly in a browser.
